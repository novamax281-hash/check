How a placement run works here

Four steps, end to end. If any of these rings familiar, this is where it gets contained.

01

Notices land in one place

When the placement cell posts an opening — a test, a drive, a walk-in — it appears here for the batches it targets. No more hunting group chats.

02

Filter by what you actually are

Branch, section, batch, eligibility. What doesn't apply to you is filtered out before you ever see it.

03

Apply in one click

Your profile is already the application — CGPA, courses, tenth and twelfth. You submit, the coordinator sees your name, and the status moves.

04

Track each round, all the way to the offer

Online test, technical interview, HR — you'll see which round you cleared, what's next, and where it stands. No one has to ask the office.

ii.

iv.
Offers & results

Selected, placed, rejected — the honest status, in writing.

A note on coordinators

The admin assigns each department's coordinators, and coordinators see only the students assigned to them. No coordinator opens the whole database by accident — which is exactly how it should stay.
